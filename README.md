## 👨‍💻 Sobre mim

Sou **Desenvolvedor de Software Júnior**, formado como **Técnico em Desenvolvimento de Sistemas pelo SENAI** e atualmente cursando **Ensino Superior em Análise e Desenvolvimento de Sistemas pela Faculdade CDL**.
