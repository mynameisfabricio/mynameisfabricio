Procuro entender o problema antes de escolher a tecnologia.

Tenho facilidade para trabalhar com diferentes tecnologias e áreas do desenvolvimento, transitando entre **Front-end, Back-end, Mobile, Banco de Dados, APIs e Infraestrutura** conforme a necessidade da solução.
